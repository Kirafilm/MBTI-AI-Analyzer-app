## 修复：登入按钮无效
- profile 路由从 `presentation: "modal"` 改为普通 push 方式
- 原因：modal 内部 `router.push("/auth/login")` 在 Expo Router/React Navigation 中可能因 navigator context 隔离而失效
- 改为普通 push 后，profile 和 auth/login 都在同一个 root Stack 中，导航可靠
